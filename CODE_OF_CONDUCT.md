# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful.
- Be constructive.
- Assume good intent.
- Avoid personal attacks.
- Keep security discussions responsible and professional.

## Unacceptable behavior

- Harassment
- Threats
- Discrimination
- Publishing private information
- Sharing credentials, tokens, or secrets

## Enforcement

Maintainers may remove comments, close issues, or block participants who violate this code of conduct.
